 # Fancy Restaurant Page

A responsive restaurant website built to showcase menu offerings, dining ambiance, and table reservations, hosted at [fancyrestarentpage.com](http://fancyrestarentpage.com).

## Features

- **Landing & Showcase (`index.html`):** Clean, structured layout presenting the restaurant's brand, featured dishes, and dining experience.
- **Table Reservation (`reserve your table`):** Dedicated reservation section/page allowing guests to book a table.
- **Custom Domain & Static Hosting:** Configured with a `CNAME` record for `fancyrestarentpage.com` and `.nojekyll` for direct static deployment via GitHub Pages.

## Project Structure

```text
fancyrestarentpage/
├── .github/             # GitHub workflows and repository configurations
├── .nojekyll            # Bypasses Jekyll processing on GitHub Pages
├── CNAME                # Custom domain configuration (fancyrestarentpage.com)
├── index.html           # Main landing page
├── reserve your table   # Table reservation page/file
└── README.md            # Project documentation
